# Blade Spin - Privacy Policy

Published policy page for the Android game **Blade Spin** (`com.nnastudio.knifehit`).

- Live page: https://anhngocnguyen1034.github.io/blade-spin-privacy/
- This URL is the one entered in the Play Console listing and opened by the
  game's Settings screen.

The game collects no personal data: it runs offline, stores progress only in
the app's private storage on the device, has no ads, no analytics and no
internet permission.
