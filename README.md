# Blade Spin - Privacy Policy

Published policy page for the Android game **Blade Spin** (`com.nnastudio.bladespin`).

- Live page: https://anhngocnguyen1034.github.io/blade-spin-privacy/
- This URL is the one entered in the Play Console listing and opened by the
  game's Settings screen.

The game collects no personal data: progress stays in the app's private
storage on the device and there are no ads and no advertising ID. Anonymous
usage statistics go to Google Firebase Analytics; the Play rating window may
be shown a few times. The text matches data/privacy.json in the game.
